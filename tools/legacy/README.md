# Archived build scripts

These are one-off scripts used while building `index.html` — they mutate the file
in place and were run once each, in an order that is no longer recorded. Several
contradict each other (`fix_mobile.js` / `fix_mobile_again.js`,
`upgrade_to_webgl.js` / `revert_webgl.js`).

They are kept for history only. **Nothing here is part of the build.**
The deliverable is `index.html` plus `assets/`.
